# 散布図と相関係数

『大学入学共通テスト「情報Ⅰ」対策問題集』（技術評論社, ISBN 978-4-297-15084-6）pp.26-28 連動Webアプリ。

**公開URL**: https://technical-reviewer-information1.github.io/scatter-correlation/

相関係数は「点の並び方」を1つの数字に押し込めたものです。点をつかんで動かしながら、数字と見た目の対応を体に入れましょう。

## 技術

静的な HTML / CSS / JavaScript のみで動作します。ビルド不要・外部CDN不使用・サーバ通信なし。
GitHub Pages で配信しており、Python や Streamlit は不要です。スマートフォン／タブレット／PC に対応。

```
index.html
css/style.css   全アプリ共通スタイル
css/app.css     このアプリ固有のスタイル
js/app.js       画面制御
```

`app.py` は旧版（Streamlit Community Cloud 用）です。
